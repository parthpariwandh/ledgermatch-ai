# ledgermatch-ai

![Status](https://img.shields.io/badge/status-buildathon%20prototype-blue)
![Track](https://img.shields.io/badge/Razorpay-AI%20Finance%20Controller-navy)
![Method](https://img.shields.io/badge/rules%20%2B%20fuzzy%20%2B%20LLM-agent-green)

LedgerMatch AI is a multi source reconciliation agent for Razorpay AI Buildathon 2026, Track 4: AI Finance Controller. It reconciles records across Razorpay settlements, bank statements, and internal ledgers, and it reports the match rate together with the exceptions it could not close.

## At a glance

- Hybrid rule, fuzzy, and language model matching
- Built for 100 or more records in a working set
- Honest exception reporting, not a forced match
- Author: Parth Pariwandh, Jadavpur University
